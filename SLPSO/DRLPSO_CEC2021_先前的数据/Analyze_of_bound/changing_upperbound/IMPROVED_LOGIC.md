# 改进的比较逻辑说明

## 📊 修改内容

### 原逻辑 (修改前)

```python
if p_value >= 0.05:
    return "≈"
else:
    if baseline_mean < compare_mean:
        return "+"  # 只比较均值
    else:
        return "-"
```

**问题**: 只考虑均值，忽略了稳定性（方差）

---

### 新逻辑 (修改后)

```python
# 1. 先判断是否有显著差异
if p_value >= 0.05:
    return "≈"

# 2. 有显著差异时，先比较均值
mean_diff_ratio = abs(baseline_mean - compare_mean) / (abs(baseline_mean) + 1e-10)

if mean_diff_ratio > 0.01:  # 均值差异 > 1%
    if baseline_mean < compare_mean:
        return "+"  # 基准均值更小（更好）
    else:
        return "-"
        
# 3. 均值相近时，比较标准差（稳定性）
else:
    if baseline_std < compare_std:
        return "+"  # 基准更稳定
    else:
        return "-"
```

## 🎯 比较决策树

```
开始
  ↓
Wilcoxon检验: p-value
  ↓
p >= 0.05 ?
  ↓
YES → 返回 "≈" (无显著差异)
  ↓
NO → 有显著差异
  ↓
均值差异 > 1% ?
  ↓
YES → 比较均值
  ↓                          ↓
baseline_mean < compare_mean?
  ↓                          ↓
YES → "+" (基准更好)    NO → "-" (比较更好)

  ↓
NO → 均值相近，比较标准差
  ↓
baseline_std < compare_std?
  ↓                          ↓
YES → "+" (基准更稳定)  NO → "-" (比较更稳定)
```

## 💡 设计理念

### 1. **三层判断机制**

#### 第一层: 统计显著性
- **工具**: Wilcoxon符号秩检验
- **阈值**: p < 0.05
- **作用**: 确认差异是否真实存在

#### 第二层: 性能优劣 (均值)
- **指标**: 均值差异比例
- **阈值**: > 1%
- **作用**: 判断性能哪个更好（值越小越好）

#### 第三层: 稳定性 (方差)
- **指标**: 标准差
- **条件**: 均值相近时
- **作用**: 在性能相当时，选择更稳定的

## 📐 实际案例

### 案例1: 均值差异显著

```python
配置A: mean=1.00E-220, std=0.00E+00
配置B: mean=3.00E-220, std=0.00E+00

步骤:
1. Wilcoxon检验 → p=0.001 < 0.05 ✅ 有显著差异
2. 均值差异 = |1.00E-220 - 3.00E-220| / 1.00E-220 = 200% > 1% ✅
3. 比较均值: 1.00E-220 < 3.00E-220
4. 结果: "+" (配置A更好)
```

### 案例2: 均值相近，比稳定性

```python
配置A: mean=5.00E+01, std=8.00E+01
配置B: mean=5.05E+01, std=7.00E+01

步骤:
1. Wilcoxon检验 → p=0.02 < 0.05 ✅ 有显著差异
2. 均值差异 = |5.00 - 5.05| / 5.00 = 0.01 = 1% ❌ 不大于1%
3. 比较标准差: 8.00 > 7.00
4. 结果: "-" (配置B更稳定，更好)
```

### 案例3: 无显著差异

```python
配置A: mean=4.81E+01, std=1.04E-01
配置B: mean=4.81E+01, std=1.81E-01

步骤:
1. Wilcoxon检验 → p=0.50 >= 0.05
2. 结果: "≈" (无显著差异)
```

## 🔍 为什么这样设计?

### 1. **符合实际需求**
在优化算法比较中:
- **首要目标**: 找到更优解 (均值)
- **次要目标**: 保证稳定性 (方差)

### 2. **避免误判**
如果只看均值:
```
算法A: mean=100, std=1   (稳定)
算法B: mean=99,  std=50  (不稳定)
```
纯看均值B好，但B波动大，不可靠！

### 3. **阈值选择 (1%)**
- 太小 (如0.1%): 微小差异也判为不同，过于敏感
- 太大 (如10%): 明显差异也判为相近，不够敏感
- **1%**: 平衡点，既能识别实质差异，又不会误判

## 📊 统计学解释

### Wilcoxon符号秩检验

**原理**:
- 非参数检验，不假设数据分布
- 比较两组配对样本的差异
- 适合小样本 (n=30)

**零假设 H0**: 两组数据无差异  
**备择假设 H1**: 两组数据有差异  
**决策**: p < 0.05 → 拒绝H0 → 有显著差异

### 效应量 (Effect Size)

均值差异比例 = `|mean1 - mean2| / mean1`

- < 0.01 (1%): 可忽略差异
- 0.01 - 0.05: 小差异
- 0.05 - 0.10: 中等差异
- \> 0.10: 大差异

## 🎓 学术论文中的描述

### 方法部分可以这样写:

> 为评估不同参数配置的性能，我们采用三层比较框架：
> 
> 1. **统计显著性检验**: 使用Wilcoxon符号秩检验(α=0.05)判断两组结果是否存在显著差异。
> 
> 2. **性能比较**: 当存在显著差异时，首先比较算法的平均性能(均值)。若均值差异超过1%，则认为性能存在实质性差异。
> 
> 3. **稳定性比较**: 当均值相近(差异≤1%)时，进一步比较算法的稳定性(标准差)，标准差更小的算法被认为更优。
> 
> 该框架综合考虑了算法的性能和鲁棒性，确保比较结果的全面性和可靠性。
