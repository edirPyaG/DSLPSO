# 改进的比较逻辑说明

## 核心逻辑 (五步判断)

### 第一步：对均值进行显著性检验
```python
使用 Wilcoxon signed-rank test 检验两组数据的均值是否有显著差异
零假设 H0: 两组数据的均值无差异
显著性水平: α = 0.05
```

### 第二步：如果均值有显著差异 (p < 0.05)
```
直接根据均值大小返回结果:
- 如果 baseline_mean < compare_mean → 返回 '+' (基准更好)
- 如果 baseline_mean > compare_mean → 返回 '-' (比较配置更好)
```

### 第三步：如果均值无显著差异 (p ≥ 0.05)
```python
对方差进行显著性检验:
使用绝对偏差作为方差的代理变量
baseline_abs_dev = |baseline_data - baseline_mean|
compare_abs_dev = |compare_data - compare_mean|
再次使用 Wilcoxon test 检验方差是否有显著差异
```

### 第四步：如果方差有显著差异 (p < 0.05)
```
根据方差(标准差)大小返回结果:
- 如果 baseline_std < compare_std → 返回 '+' (基准更稳定,更好)
- 如果 baseline_std > compare_std → 返回 '-' (比较配置更稳定,更好)
```

### 第五步：如果方差也无显著差异 (p ≥ 0.05)
```
返回 '≈' (约等于,无显著差异)
```

## 与旧逻辑的对比

### 旧逻辑 (已废弃)
```
1. 对原始数据进行一次 Wilcoxon 检验
2. 如果 p ≥ 0.05 → 直接返回 '≈'
3. 如果 p < 0.05 且均值差异 > 1% → 比较均值
4. 如果 p < 0.05 但均值差异 ≤ 1% → 比较方差
```

**问题:**
- 方差比较没有经过显著性检验
- 使用固定的 1% 阈值判断均值是否"相近"过于主观

### 新逻辑 (当前版本)
```
1. 对均值进行 Wilcoxon 显著性检验
2. 如果均值有显著差异 → 比较均值,返回结果
3. 如果均值无显著差异 → 对方差进行 Wilcoxon 显著性检验
4. 如果方差有显著差异 → 比较方差,返回结果
5. 如果方差也无显著差异 → 返回 '≈'
```

**优点:**
- 均值和方差都经过严格的统计检验
- 避免使用主观阈值
- 逻辑更清晰:先看性能(均值),再看稳定性(方差)
- 符合统计学最佳实践

## 代码实现关键点

```python
# 1. 均值显著性检验
_, p_value_mean = wilcoxon(baseline_data, compare_data)

# 2. 方差显著性检验 (使用绝对偏差)
baseline_abs_dev = np.abs(baseline_data - baseline_mean)
compare_abs_dev = np.abs(compare_data - compare_mean)
_, p_value_var = wilcoxon(baseline_abs_dev, compare_abs_dev)
```
